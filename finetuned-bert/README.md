# SentenceTransformer based on sentence-transformers/all-mpnet-base-v2

This is a [sentence-transformers](https://www.SBERT.net) model finetuned from [sentence-transformers/all-mpnet-base-v2](https://huggingface.co/sentence-transformers/all-mpnet-base-v2). It maps sentences & paragraphs to a 768-dimensional dense vector space and can be used for semantic textual similarity, semantic search, paraphrase mining, classification, clustering, and more.

## Model Details

### Model Description
- **Model Type:** Sentence Transformer
- **Base model:** [sentence-transformers/all-mpnet-base-v2](https://huggingface.co/sentence-transformers/all-mpnet-base-v2) <!-- at revision e8c3b32edf5434bc2275fc9bab85f82640a19130 -->
- **Maximum Sequence Length:** 384 tokens
- **Output Dimensionality:** 768 dimensions
- **Similarity Function:** Cosine Similarity
- **Supported Modality:** Text

### Full Model Architecture

```
SentenceTransformer(
  (0): Transformer({'transformer_task': 'feature-extraction', 'modality_config': {'text': {'method': 'forward', 'method_output_name': 'last_hidden_state'}}, 'module_output_name': 'token_embeddings', 'architecture': 'MPNetModel'})
  (1): Pooling({'embedding_dimension': 768, 'pooling_mode': 'mean', 'include_prompt': True})
  (2): Normalize({})
)
```

## Usage

### Direct Usage (Sentence Transformers)

First install the Sentence Transformers library:

```bash
pip install -U sentence-transformers
```
Then you can load this model and run inference.
```python
from sentence_transformers import SentenceTransformer

# Download from the 🤗 Hub
model = SentenceTransformer("sentence_transformers_model_id")
# Run inference
sentences = [
    'Backend Engineer with 9 years of experience based in Bangalore. B.S. in Computer Science. Previously at Fathom and Acme Corp, where I helped to optimize application performance and reliability, collaborate with cross-functional teams to ship features, and write clean, testable, well-documented code. Core skills include REST APIs, Java, Python, Git, TypeScript, GraphQL, Node.js, and React. Proven track record of delivering results in fast-paced environments and collaborating across teams to drive measurable impact.',
    'Globex is hiring a UX/UI Designer (Bangalore). In this role you will conduct user research and usability testing, advocate for accessible, user-centered design, create wireframes, prototypes, and high-fidelity mockups, and collaborate closely with product and engineering. We are looking for 2+ years of experience and strong skills in user research, accessibility, wireframing, interaction design, Figma, Sketch, design systems, and usability testing. You should be a collaborative team player who thrives on ownership and impact.',
    'BrightData is hiring a Senior Data Analyst (Toronto). In this role you will identify trends and translate them into recommendations, build dashboards and reports for business stakeholders, automate recurring reporting workflows, and maintain data quality and documentation. We are looking for 2+ years of experience and strong skills in Google Analytics, reporting, Tableau, Power BI, Python, and data visualization. You should be a collaborative team player who thrives on ownership and impact.',
]
embeddings = model.encode(sentences)
print(embeddings.shape)
# [3, 768]

# Get the similarity scores for the embeddings
similarities = model.similarity(embeddings, embeddings)
print(similarities)
# tensor([[1.0000, 0.5963, 0.2943],
#         [0.5963, 1.0000, 0.3204],
#         [0.2943, 0.3204, 1.0000]])
```
